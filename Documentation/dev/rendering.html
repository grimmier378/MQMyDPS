ImGui Rendering

Window Inventory

All rendering lives in MyDPSRenderer.cpp / MyDPSRenderer.h. The renderer exposes seven public entry points — RenderMainWindow, RenderPopOutWindows, RenderConfigWindow, RenderCombatSpam, RenderFloatingText, RenderIconPicker, and RenderConfig — all driven from OnUpdateImGui.

Styled widgets: the UI chrome (tabs, checkboxes, sliders, combos, the peer-meter header) uses the shared imanim-driven set in Widgets.{h,cpp} (namespace myui), copied from MQMyUI. OnUpdateImGui owns the iam_context. ImPlot graphs, the FCT renderer, and the in-table History tree expanders stay stock ImGui. See the dedicated Styled Widgets page for the wiring, the catalog, and how to convert a call site.

Main Window — Menu Bar

Uses ImGui::MenuItem() (not Button). The menu bar contains:

  • Stop/Start toggle — Material Design icons (ICON_MD_STOP / ICON_MD_PLAY_ARROW)
  • Reset — ICON_MD_DELETE, calls engine.ResetAll()
  • Config toggle — ICON_MD_SETTINGS
  • Separator
  • Live session DPS — colored using the "dps" color key
  • Red [COMBAT] label — shown when engine.inCombat is true

Main Window — 6 Tabs

The tab strip is a myui::PillTabBar built in RenderMainWindow (MyDPSRenderer.cpp:114). It is fed only the visible (non-popped-out) tabs; the member m_mainTab stores the selected real tab id and the returned index is mapped back through the visible-tab list. The selected tab's body is rendered below the strip via RenderTabBody(engine, m_mainTab). Tabs are TAB_CURRENT, TAB_HISTORY, TAB_TARGETS, TAB_HEALING, TAB_GRAPHS, TAB_GROUP. Right-clicking the strip opens a Pop Out menu for the active tab (see below).

Tab 1: Current Battle

RenderCurrentBattle (MyDPSRenderer.cpp:318)

Stats table with color-coded values: DPS, Duration, Total, Avg, Hits, Crits, DoTs, Pet, Non-Melee, Heals, Crit Heals. A local lambda C(key) fetches from damageColors. Column count scales dynamically with window width.

Below the stats table: a target sub-table (colored with "dmg-target") showing Name, DPS, Hits, Total per target, and a heal sub-table (colored with "heal-target") showing Player, Heals, Total per healed player.

A collapsible peer live-meter (RenderPeerLiveMeter, MyDPSRenderer.cpp:1097) sits at the top of this tab, wrapped in a myui::BeginAnimatedHeader: an adaptive table (base Player/DPS/Total, expanding to Crit/DoT/Pet/Hits/Heals/Status as width allows) showing the group's live numbers. It respects settings.peerFilterMode.

Tab 2: History

RenderHistory (MyDPSRenderer.cpp:434)

13-column table with ImGuiTableFlags_Hideable | ImGuiTableFlags_Reorderable. The Battle# column has NoHide.

Columns: Battle#, DPS, Duration, Avg, Melee (computed: totalDamage minus DD/DoT/Pet/DS), Crits, DoTs, Pet, Non-Melee, Heals, Crit Heals, Total Damage, Total Heals.

Rows sorted by sortNewest (iterates forward or reverse through battleHistory). Each row is a stock ImGui::TreeNode (intentionally not converted to the animated tree node, whose clipped child would fight the surrounding table layout); expansion shows per-target sub-rows and per-heal-target sub-rows. The Clr lambda is hoisted before the loop so both battle-level and sub-rows share the same color lookup.

Tab 3: Targets

RenderTargets (MyDPSRenderer.cpp:574)

Two sections: current battle targets (5-column table: Name, DPS, Hits, Avg, Total) if a battle is active, followed by all session targets from sortedSessionTargets (4-column table: Name, Hits, Avg, Total).

Tab 4: Healing

RenderHealing (MyDPSRenderer.cpp:948)

5-column table from sortedSessionHeals with columns: Player (NoHide), Direct Heals, Crit Heals, Count, Total. Features Hideable | Reorderable flags. Pie chart rendered below using ImPlot.

Tab 5: Graphs

RenderGraphs (MyDPSRenderer.cpp:646)

Bordered child with 8px padding. 4 myui::StyledCheckbox toggles select chart types (all can show simultaneously):

  • DPS Line — Single DPS line per battle with scrollbar navigation
  • Damage Breakdown — 3 Y-axes: Damage (Melee/DD/DoT/Pet on Y1), Crits (Y2), Heals/CritHeals (Y3)
  • Bar Chart — 7 grouped bars (Melee, DD, DoT, Pet, Crit, Heals, Crit Heals), groupWidth=0.8
  • Pie Chart — Damage distribution by target from sortedSessionTargets

Data is cached in vectors and rebuilt when battle count changes. Each graph type has its own scroll state with auto-scroll support and a myui::StyledSliderInt scrollbar.

Tab 6: Peers

RenderGroup (MyDPSRenderer.cpp:1180) — the cross-character view. It reads engine.actors.VisiblePeers(static_cast<PeerFilterMode>(engine.settings.peerFilterMode)) and presents three sub-tabs via a myui::PillTabBar (m_groupSubTab); the selected body renders in a switch below the strip:

  • Live (RenderGroupLive, :1218) — 11-column live table per peer: Player, Class, DPS, Total, Hits, Crit, DoT, Pet, Non-Melee, Heals, Status (Combat in red, else dimmed).
  • History (RenderGroupHistory, :1276) — encounters built by BuildEncounters (groups peer battles within kEncounterGapToleranceMs = 5000); a tree of encounter → per-peer rows (DPS, Total, Duration, Heals), ordered by settings.sortNewest.
  • Graphs (RenderGroupGraphs, :1379) — a session-average DPS pie by character (self labelled "(you)") and a per-encounter grouped DPS bar chart (last 20 encounters, one bar per peer, colored by peer.color).

At the top of the Peers tab, a myui::StyledCheckbox (Show Peers) and a 4-way myui::PillTabBar set the peer filter (the pill index maps directly to peerFilterMode 0–3):

static const char* kPeerFilters[] = { "All", "Server", "Group", "Raid" };
engine.settings.peerFilterMode =
    myui::PillTabBar("##peerfilter", kPeerFilters, 4, engine.settings.peerFilterMode);

The value is cast to PeerFilterMode when passed to VisiblePeers. See Cross-Character Sharing for what each mode includes.

Tab Pop-Out

Any of the six tabs can be detached into its own window. State lives in bool m_tabPopOut[TAB_COUNT] (MyDPSRenderer.h:72). Because PillTabBar has no per-pill context hook, pop-out is re-attached at the strip level: after the bar, ImGui::IsItemHovered() && ImGui::IsMouseClicked(Right) opens a popup whose "Pop Out" item sets m_tabPopOut[m_mainTab] = true for the active tab. Popped-out tabs are excluded when building the visible-labels array each frame. RenderPopOutWindows (MyDPSRenderer.cpp:267) draws one window per popped tab (default 520x360, title "MyDPS - {Tab}##MQMyDPS_PopOut_{t}_{charName}") and reuses the same RenderTabBody logic; closing the window clears the flag and the tab returns to the strip.

Icon Picker

RenderIconPicker (MyDPSRenderer.cpp:1960) is a modal-style dialog opened from the FCT config per-type icon table. A myui::PillTabBar selects Spell Icons vs Item Icons (the latter offset by FCT_ITEM_ICON_OFFSET), driving the m_iconPickerShowItems flag; a paginated icon grid follows with a StyledSliderFloat scale and StyledSliderInt page control. Hovering shows the icon ID and type. Picker state (m_iconPickerOpen, m_iconPickerKey, m_iconPickerPage, m_iconPickerShowItems, m_iconPickerScale) lives in the renderer.

Config Window — 5 Tabs

The config tab strip is a myui::PillTabBar (m_configTab) wrapped in an anonymous scope; each tab body renders in a if (m_configTab == N) block. Settings chrome uses the styled widgets throughout.

Display

12 booleans rendered via a BoolEntry array through myui::StyledCheckbox (sortNewest, showType, showTarget, showMyMisses, showMissMe, showHitMe, showCritHeals, showDS, addPet, autoStart, spamClickThrough). Two StyledSliderInt: DisplayTime and BattleEndDelay. Two StyledSliderFloat: FontScale and SpamFontScale (range 0.5–2.0). Column count scaling: max(1, WindowWidth / divisor).

Colors

UI-only colors: background alpha slider plus 6 UI color keys (dmg-target, heal-target, dps, duration, avg, total). Damage-type colors (melee verbs, non-melee, dot, crit, etc.) are edited per-type in the FCT tab. Color pickers use ImGuiColorEditFlags_NoInputs.

FCT

Enable + Distinct Melee myui::StyledCheckbox, 7 StyledSliderFloat (IconScale, FloatDistance, ArcScale, Lifetime, BaseFontSize, FontScale, ShadowOffset). Bone Anchors section with 2 StyledCombo boxes (Player Bone / Other Bone) listing 28 bones with the 6 most practical ones first (Head, Chest, Pelvis, Legs, Left Boot, Right Boot). Per-type color/icon table showing 19 types when Distinct Melee is on, 11 when off. (These configure FCT; the FCT renderer itself stays stock.)

The color/icon table is responsive: each type is a 4-column set (Type · Color swatch · Icon picker · Actions), and the table tiles fctSets = max(1, windowWidth / 280) sets per row, filling row-major. Visible types are collected into a list (honoring Distinct Melee) and chunked; columns repeat per set with "Type##i"-style unique IDs. Per-type actions are icon buttons: ICON_FA_BAN removes the icon / shows none (override to FCT_ICON_NONE) and ICON_FA_UNDO resets to default (erase the override). FontAwesome glyphs come from <imgui/fonts/IconsFontAwesome.h>.

Theme

myui::StyledCombo with 11 themes from Theme.h (DrawThemePicker). themeIdx is persisted to INI. ApplyTheme/ResetTheme wraps the main and config windows (but not FCT).

Patterns

Exposes all pattern definitions from MyDPSPatternEngine for in-game editing. Includes Save and Reload buttons, plus a display of the JSON file path. Two editable tables:

  • Chat Patterns: 3-column table (Enable myui::StyledCheckbox, Key label, Pattern myui::StyledEditField — readonly text that opens a click-to-edit Accept/Cancel popup) for the 15 standard patterns
  • Pet Patterns: Same layout for the 2 pet patterns

Users can toggle individual patterns on/off, edit the raw Blech pattern text, then Save to persist to JSON and Reload to re-register the updated Blech events.

Combat Output Overlay

No title bar, no focus on appearing (ImGuiWindowFlags_NoTitleBar | ImGuiWindowFlags_NoFocusOnAppearing). Click-through via ImGuiWindowFlags_NoInputs when spamClickThrough=true. Uses independent spamFontScale. Background alpha controlled by settings.bgColor.w.

Iterates recentRecords in reverse (newest on top). Entries expire after displayTime seconds. Each entry is colored by its damage type color key, with pet types overridden to "pet" and melee using the attack verb as key.
