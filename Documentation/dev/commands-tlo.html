TLO: ${MyDPS}

Implemented in MyDPSTLO.cpp / MyDPSTLO.h. Provides read-only access to engine state. Registered as a top-level object via AddTopLevelObject("MyDPS", ...) during RegisterMyDPSTLO().

Methods

${MyDPS.Reset} — calls ResetAll() on the engine, returns true.

Target Lookup

The Target member accepts an index that is treated as a spawn ID when the whole string is numeric (IsNumber() → FindTargetBySpawnID(GetIntFromString(Index, 0)), a direct map lookup in currentTargets) and as a name otherwise (FindTargetByName, a linear scan matching data.name). Both helpers come from mq/base/String.h.

Spawn-ID form is most reliable — it survives name collisions when multiple mobs share the same display name.

Macro Examples

/echo Current DPS: ${MyDPS.BattleDPS}
/echo Target damage: ${MyDPS.Target[${Target.ID}].TotalDamage}
/echo Session total: ${MyDPS.TotalDamage}
/if (${MyDPS.InCombat}) /echo In combat!
/echo Goblin DPS: ${MyDPS.Target[a goblin].DPS}
