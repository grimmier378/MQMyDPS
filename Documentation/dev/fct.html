Floating Combat Text

Overview

Header-only implementation in MyDPSFloatingText.h. Renders floating damage/heal numbers over mob heads in 3D world space. Uses a ring buffer of 64 entries with no dynamic allocation during combat.

Architecture

FCTManager manages the lifecycle of all entries. Three main methods:

  • AddEntry — creates a new entry from a DamageRecord, assigns angle slot and arc
  • Update — advances lifetime of each active entry, cleans up stale spawn angle slots
  • Render — projects each active entry to screen coordinates and draws text + icons via ImGui::GetBackgroundDrawList()

Bone-Anchored Projection

ProjectSpawnToScreen (MyDPSFloatingText.h:295). Configurable bone per spawn type: fctBonePlayer (default 11 = Chest) for players, fctBoneOther (default 20 = Legs) for NPCs. Stored as int, cast to EBones at use site.

28 bones defined in GetFCTBoneList (MyDPSFloatingText.h:24). Bone position obtained via GetBoneByIndex/GetBoneWorldPosition, with fallback to pSpawn->Y/X/Z + AvatarHeight when bone lookup fails. Projects through camera eye-space matrix using worldToEyeCoef. Rejects behind-camera entries (Ez <= 0).

The default split (chest for players, legs for NPCs) provides better visibility on large NPC models. Users can change both via the FCT config tab.

Animation Phases

PhaseTimingEffectEasing
Pop-inFirst 0.3sScale 1.4 → 1.0EaseOutQuad
FloatFull lifetimeDirectional movement + arcEaseOutQuad (distance)
Fade-outLast 40% (t > 0.6)Alpha 1.0 → 0.0Linear

The float math for each frame:

float t = lifetime / maxLifetime; float distance = fctFloatDistance * EaseOutQuad(t); float dx = cos(dirAngle) * distance; float dy = sin(dirAngle) * distance; float arcT = sin(PI_F * t); // peaks at t=0.5 float perpX = -sin(dirAngle) * arcAmount * arcT; float perpY = cos(dirAngle) * arcAmount * arcT;

Spread and Grouping

8 angle slots (NUM_ANGLE_SLOTS) in the upper semicircle, ranging from -150 degrees to -30 degrees with -90 degrees (straight up) as the first slot. The full slot layout:

Slot 0: -90.0° (straight up) Slot 1: -67.5° (up-right) Slot 2: -112.5° (up-left) Slot 3: -45.0° (diagonal right) Slot 4: -135.0° (diagonal left) Slot 5: -30.0° (steep right) Slot 6: -150.0° (steep left) Slot 7: -78.75° (slight right of up)

Per-spawn slot tracking in m_spawnAngleSlot (unordered_map<int, int>). Each new entry for a spawn advances the slot counter. Random perpendicular arc via uniform_real_distribution(0.5, 1.0) with alternating sign. Slots reset when no active entries remain for a spawn.

Display Formatting

  • Heals: "+" prefix (e.g., "+1.2k")
  • Incoming damage: "-" prefix (e.g., "-500")
  • Others: plain number

FormatNumber: values >= 1M display as X.Xm, >= 1K as X.Xk, otherwise raw integer.

Drop Shadow

Each text entry is rendered twice: first a shadow at (x + offset, y + offset) in black at 80% alpha, then the colored text on top. Shadow offset scales proportionally: fctShadowOffset * (fontSize / fctBaseFontSize).

Custom Icon Picker

The fctIconOverrides map allows per-type icon customization. 19 types from GetFCTTypeInfoList are available when fctDistinctMelee=true (individual melee verbs); when false, melee verbs collapse to a single entry. The picker window provides Spell/Item tabs with paginated grids and a scale slider.

Performance

unordered_set optimization in Update(): builds a set of active spawn IDs in a single pass over entries, then checks m_spawnAngleSlot membership via set lookup instead of a linear scan per entry. Stale spawn slots are erased in-place.

Bone Anchor Config

Two combo boxes in the FCT config tab: Player Bone and Other Bone. Both list 28 bones from GetFCTBoneList, with the 6 most practical options first:

  1. Head (index 0)
  2. Chest (index 11)
  3. Pelvis (index 14)
  4. Legs (index 20)
  5. Left Boot (index 21)
  6. Right Boot (index 22)

A separator divides these from the remaining 22 bones (Helm, Guild, Primary, Secondary, Shield, Blood Spurt, Tunic, Hair, Beard, Eyebrows, Left Bracer, Right Bracer, Spell, Camera, Arms, Left Glove, Right Glove, Torch, Facial, Tattoo, Left Shoulder, Right Shoulder).
