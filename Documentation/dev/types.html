Types & Constants

Core data structures live in MyDPSData.h and MyDPSPatternEngine.h. The DamageType enum, DamageRecord struct, and accumulator structs form the data pipeline from the pattern engine through rendering. The PatternDef struct defines individual Blech patterns. The cross-character peer types (PeerRecord, PeerBattle, PeerFilterMode) live in MyDPSActors.h — see the Peer Types section below.

These back the Peers tab and peer live-meter. They are populated from incoming protobuf messages (see Cross-Character Sharing) and from the locally-built self record.
