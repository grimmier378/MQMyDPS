MQMyChat Integration

Overview

MQMyDPS can send formatted battle reports to MQMyChat's "MyDPS" channel. Entirely optional — if MQMyChat is not loaded, SendToMyChat() does nothing.

How It Works

Integration uses MQMyChat's exported C++ plugin interface, declared in the vendored header MyChatAPI.h. The accessor mqmychat::GetChatAPI() wraps mq::GetPluginInterface("MQMyChat") and returns nullptr when MQMyChat isn't loaded. (There is no longer any ParseMacroData() / ${MyChat.Send[...]} TLO-expression path — that approach was replaced by the direct interface call.)

LoadCharacterSettings() records IsPluginLoaded("MQMyChat") into m_myChatLoaded for reference, but the live helpers always re-query the interface rather than trusting that cached flag.

SendToMyChat(message) (MQMyDPS.cpp:1392) fetches the interface and, when present, calls chat->Send("MyDPS", message). Output(message) (MQMyDPS.cpp:1398) routes the same way: to the MyDPS channel when MQMyChat is loaded, otherwise to the normal MQ chat window via WriteChatf — exclusive, never both.

MQMyChat is not a link-time dependency. Only the lightweight MyChatAPI.h interface header is vendored into the plugin; at runtime the interface is resolved by name via GetPluginInterface("MQMyChat"). The header is refreshed from upstream with Update-MyChatAPI.ps1.

What Gets Sent

/mydps report — single session summary line:

[MQMyDPS] Session DPS: 1234.5 | Total: 45.6k | Hits: 312

Color codes: \at (teal) prefix, \ay (yellow) DPS, \ag (green) total, \aw (white) hits.

FinalizeBattle() — multi-line battle summary when damage > 0:

Line 1 — battle header:

[MQMyDPS] Battle #3 ended: DPS 1234.5 | Dmg 45.6k | Hits 312 | Dur 37s

Per damage target:

  a goblin (#12345) - DPS 980.0 | Dmg 36.2k | Hits 245

Target names \ar (red), spawn IDs \ap (purple).

Per heal target (if heals occurred):

  Healed Grimmier - 8.4k (12 heals)

Label \ao (orange), player \at (teal), amount \ag (green).
