Styled Widgets (imanim)

MQMyDPS's UI chrome uses a shared, theme-driven, animated widget set that replaces stock ImGui controls with a consistent vocabulary: sliding pill tabs, animated checkboxes, glowing-rail sliders (with a Ctrl+click edit popup), custom combos, a pill→bordered-box collapsing header, animated buttons (StyledButton), and a click-to-edit text field (StyledEditField — a readonly display that opens a cursor-anchored Accept/Cancel popup). Motion is driven by imanim (iam_*), the animation library compiled into MQ core's ImGui. The set lives in Widgets.{h,cpp} (namespace myui).

Animations default on. A global gate, myui::SetAnimationsEnabled(bool) / AnimationsEnabled(), can snap every styled widget to its resting state. MQMyDPS keeps it at its default (true) and exposes no toggle — nothing to wire.
Source of truth. These files are copied from MQMyUI's Core/Widgets.{h,cpp} and kept content-identical so the whole MQMy* suite shares one vocabulary. Do not diverge MQMyDPS's copy; pull updates from MyUI instead. Full integration rules, the tuned style constants, reveal internals, and gotchas live in the MQMyUI KB → Styled & Animated Widgets (D:\CLAUDE\MQMyUI\KnowledgeBase\styled-widgets.md). Tuned interactively in D:\CLAUDE\MQMyUI\demos\style-playground.html.

imanim context wiring

imanim state lives in a file-static current context that is not valid-by-default inside a plugin DLL, so the plugin owns a context and makes it current around its render pass. All of this is in MQMyDPS.cpp:

static iam_context* s_iamCtx = nullptr;            // MQMyDPS.cpp

PLUGIN_API void OnUpdateImGui()                     // :117
{
    if (!g_dpsEngine || GetGameState() != GAMESTATE_INGAME) { return; }

    if (!s_iamCtx)
    {
        s_iamCtx = iam_context_create();
        iam_context_set_current(s_iamCtx);
        iam_set_lazy_init(false);                   // animate on first change, don't snap
    }
    iam_context* prevCtx = iam_context_set_current(s_iamCtx);
    // NB: no iam_update_begin_frame() here -- the host drives the shared clock.

    s_renderer.RenderMainWindow(*g_dpsEngine);
    /* ... the other Render* calls ... */

    iam_context_set_current(prevCtx);
}

PLUGIN_API void ShutdownPlugin()                    // :32
{
    /* ... */
    if (s_iamCtx) { iam_context_destroy(s_iamCtx); s_iamCtx = nullptr; }
}
Three things you must not get wrong:
  • Do not call iam_update_begin_frame() in the plugin — the host (MQ2Main ImGuiManager) already advances imanim's shared clock once per frame. Calling it again runs every animation at 2× speed.
  • Disable lazy-init (iam_set_lazy_init(false)) on the owned context, or a channel whose first target equals its init value is never created and the widget snaps instead of tweening (tab pill, reveal heights).
  • Destroy the context on unload. iam_context_destroy find_erases it from imanim's global list; skip it and the host's next per-frame update walks a freed pointer and crashes.

No .vcxproj changes are needed beyond compiling Widgets.cpp: the iam_* symbols are IMGUI_API, imported from MQ2Main.dll via the already-linked mq2main.lib, and the imgui/imanim/im_anim.h include path comes from Plugin.props.

The PillTabBar model

Stock tabs render their body inline between BeginTabItem/EndTabItem. PillTabBar instead returns the selected index; the caller stores it (e.g. in a member) and renders the matching body below the strip. MyDPS uses three patterns:

  • Peers sub-tabs / Icon Picker — store the index, render the body in a switch.
  • Config tabs — the bar replaces BeginTabBar; an anonymous scope keeps the original brace/indent structure and each former BeginTabItem becomes if (m_configTab == N).
  • Main DPS tabs — the strip is fed only visible (non-popped-out) tabs; m_mainTab stores the real tab id and the returned index is mapped back. Pop-out is re-attached at strip level: IsItemHovered() && IsMouseClicked(Right) → popup → set m_tabPopOut[m_mainTab].

What stays stock (and why)

  • ImPlot graphs and the FCT floating-text renderer — data visualizations, not chrome (analogous to how MyUI leaves BarEngine out of the set).
  • In-table History tree expanders — the animated tree node opens a clipped BeginChild that fights ImGui table-cell layout, so those stay ImGui::TreeNode.
  • ColorEdit4 pickers — not part of the widget set.
  • The FCT icon-picker InvisibleButton hit-cells — custom-drawn icon cells, not visual buttons. (The pattern InputText fields are now StyledEditField; only these hit-surfaces stay stock.)

Gotchas

  • Auto-sizing combo popups + PillSelectable need a defined width or the pills collapse to a sliver; StyledCombo already calls CloseCurrentPopup() after a pick.
  • The styled slider needs vmin < vmax; it guards a zero range without crashing (e.g. the icon-picker Page slider when there's a single page).
  • Build and the running client's MQ core must match (ABI skew was the original imanim crash).
  • Style constants are the playground export — re-tune in the playground and re-paste, don't hand-edit blindly.
