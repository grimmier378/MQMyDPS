Macro Integration

MQMyDPS exposes your combat data through a Top-Level Object (TLO) that you can access from macros and Lua scripts. This lets you build custom triggers, displays, or automation based on your real-time DPS data.

Session Data

These members provide information about your overall session and current combat state:

ExpressionReturnsWhat It Provides
${MyDPS.Version}NumberPlugin version number
${MyDPS.DPS}NumberYour session DPS (total damage divided by total time)
${MyDPS.TotalDamage}NumberTotal damage dealt this session
${MyDPS.InCombat}TRUE/FALSEWhether you are currently in combat
${MyDPS.BattleDPS}NumberDPS for the current battle only (0 if not in combat)
${MyDPS.BattleDuration}NumberCurrent battle duration in seconds
${MyDPS.TargetCount}NumberNumber of distinct targets in the current battle
${MyDPS.BattleCount}NumberTotal number of completed battles this session

Per-Target Data

You can look up damage data for a specific target by spawn ID (number) or name (text):

ExpressionReturnsWhat It Provides
${MyDPS.Target[id].Name}TextTarget display name
${MyDPS.Target[id].SpawnID}NumberTarget spawn ID
${MyDPS.Target[id].DPS}NumberYour DPS against this target
${MyDPS.Target[id].TotalDamage}NumberTotal damage dealt to this target
${MyDPS.Target[id].HitCount}NumberNumber of hits landed on this target
${MyDPS.Target[id].Duration}NumberTime from first to last hit (minimum 1 second)
${MyDPS.Target[id].AvgDamage}NumberAverage damage per hit
Replace id with either a spawn ID number (e.g., ${MyDPS.Target[12345].DPS}) or a target name (e.g., ${MyDPS.Target[a gnoll].DPS}). Using spawn IDs is more reliable when multiple targets share the same name.

Resetting Data

You can reset all tracked data from a macro using the Reset method:

${MyDPS.Reset[]}

This method resets all tracked data and is equivalent to typing /mydps reset.

Examples

Display Session DPS in Chat

/echo Session DPS: ${MyDPS.DPS}

Check Damage Against Your Current Target

/echo Damage to ${Target.CleanName}: ${MyDPS.Target[${Target.ID}].TotalDamage}

Conditional Combat Check

/if (${MyDPS.InCombat}) /echo Currently fighting ${MyDPS.TargetCount} targets

Look Up a Named Target

/echo DPS vs goblin: ${MyDPS.Target[a goblin].DPS}

Battle Count Summary

/echo Completed ${MyDPS.BattleCount} battles this session
For the most reliable target lookups, use spawn IDs rather than names. Names can collide when multiple spawns share the same name (e.g., "a skeleton"), but spawn IDs are unique.

MQMyChat Integration

If you also have the MQMyChat plugin loaded, MQMyDPS automatically sends battle reports to the MQMyDPS chat channel when each fight ends, instead of printing them to your normal chat window. This gives you a persistent log of your combat performance that you can review in the MQMyChat window.

The integration is automatic — no configuration needed. Just have both plugins loaded:

/plugin MQMyChat
/plugin MQMyDPS

When a battle ends, MQMyDPS sends a detailed report including DPS, total damage, hit count, duration, and per-target breakdowns. The /mydps report command also routes its output to the MQMyDPS channel instead of your normal chat window when MQMyChat is loaded.

MQMyChat integration is completely optional. If MQMyChat is not loaded, MQMyDPS works exactly the same — battle reports print to your normal chat window.
