Commands

All MQMyDPS commands are typed in your EverQuest chat window and begin with /mydps. Commands are not case-sensitive.

Command Reference

CommandWhat It Does
/mydpsToggle the main DPS Report window on or off
/mydps showShow the main window
/mydps hideHide the main window
/mydps startStart tracking damage and healing. If this is the first start of the session, the session timer begins.
/mydps stopPause tracking. Your data is preserved — you can resume with /mydps start.
/mydps resetClear all recorded data — battles, targets, healing, and statistics — and start fresh.
/mydps reportPrint your current session statistics to the chat window. If MQMyChat is loaded, the report is sent to the MQMyDPS chat channel instead of your normal chat window.
/mydps configToggle the settings window
/mydps spamToggle the combat overlay (real-time damage feed). The combat overlay only displays while tracking is active.
/mydps lockToggle click-through mode on the combat overlay
/mydps fctToggle floating combat text (3D damage numbers)
/mydps peersShow or hide the peer display (see Peers)
/mydps filter all|server|group|raidChoose which characters appear in the group views
/mydps debugToggle extra logging for peer discovery
/mydps peerdebugPrint the list of known peers and message counts to chat
/mydps patterns reloadReload chat patterns from the JSON file. Use after editing patterns in-game or in the JSON file directly.
/mydps helpDisplay a list of available commands in chat

Common Workflows

Starting a New Session

If you want to track a fresh session from scratch:

/mydps reset
/mydps start

Getting a Quick Report

To see your session stats printed in chat at any time:

/mydps report

The report includes your session DPS, total damage, hit count, duration, and per-target breakdowns.

Setting Up for Combat

A typical setup for an active combat session with all visual features:

/mydps start
/mydps spam
/mydps fct

Minimal Mode

If you only want the main window with no overlays:

/mydps show
/mydps start

Make sure the combat overlay and FCT are toggled off if you enabled them previously.

You can add these commands to a macro or hotbutton for one-click setup at the start of each play session.
