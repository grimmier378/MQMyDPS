Getting Started

This page walks you through loading MQMyDPS for the first time and understanding the main interface.

Loading the Plugin

To load MQMyDPS, type the following in your EverQuest chat window:

/plugin MQMyDPS

The plugin loads automatically each session once added. To unload it, type /plugin MQMyDPS unload.

The Main Window

After loading, the DPS Report window appears. You can toggle it at any time with /mydps or /mydps show / /mydps hide.

Menu Bar

The top of the main window has a menu bar with these controls:

ButtonWhat It Does
Start / Stop (toggle)Displays "Start" when not tracking — click to begin. Displays "Stop" while tracking — click to pause without clearing data. Only one is shown at a time.
Reset (trash icon)Clear all recorded data and start fresh
Config (gear icon)Open the settings window

The menu bar always displays your session DPS in gold text (it reads 0.0 before you start tracking). During active combat, a red [COMBAT] indicator also appears.

Main Window Tabs

The main window has six tabs, each showing different aspects of your combat data:

TabWhat It Shows
Current BattleLive stats for the fight in progress — DPS, hits, crits, targets, and healed players
HistoryA sortable table of all past battles with expandable per-target breakdowns
TargetsDamage dealt to each target in the current battle and across the session
HealingHealing totals per player with a pie chart showing distribution
GraphsDPS trends, damage breakdowns, bar charts, and pie charts
PeersLive DPS, history, and graphs for all your boxed characters

Each tab is covered in detail on the Tracking Damage, Graphs & Charts, and Peers pages. Any tab can be popped out into its own window — select it, then right-click the tab bar and choose Pop Out.

Auto-Start

By default, tracking does not begin until you press play or type /mydps start. If you want tracking to begin automatically every time you log in, enable the Auto Start option in Settings.

With Auto Start enabled, you never need to remember to start tracking — it begins the moment your character enters the world.

Chat Patterns

The first time you load MQMyDPS on a server, a default set of chat patterns is generated automatically. These patterns tell the plugin how to recognize damage, healing, and miss messages from EverQuest's combat text. You can view and edit them in the Patterns tab of the settings window, See Chat Patterns for details.

Your Settings

MQMyDPS saves a separate configuration file for each character on each server. This means your shadowknight and your cleric can have completely different color schemes, FCT settings, and display preferences. Settings are saved automatically when you zone, log out, or close the config window.

The settings window with display options, accessed via the gear icon or /mydps config.
