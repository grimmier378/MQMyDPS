Combat Overlay

The Combat Overlay (also called Combat Output) is a compact, borderless window that displays a real-time feed of your damage and healing events as they happen. It sits on top of your game without a title bar, giving you a quick-glance damage readout during combat.

Toggling the Overlay

Use any of these methods to show or hide the overlay:

  • Type /mydps spam in chat
  • Toggle the Show Combat Output checkbox in Settings

What It Shows

Each line in the overlay represents a damage or healing event, displayed in this format:

[Type] Target: Damage

For example:

  • [crush] a gnoll: 2.5k — You crushed a gnoll for 2,500 damage (the label reflects the specific attack verb: crush, slash, kick, bash, pierce, backstab, bite, hit, etc.)
  • [DoT] a skeleton: 1.2k — Your DoT ticked on a skeleton for 1,200
  • [Heal] Groupmate: 3.8k — You healed a groupmate for 3,800

Entries appear in reverse chronological order (newest on top) and automatically fade out after a configurable number of seconds.

Display Options

OptionWhat It DoesWhere to Change
Show TypeInclude the damage type label (e.g., [crush], [DoT])Settings → Display
Show TargetInclude the target nameSettings → Display
Display TimeHow many seconds each entry stays visible (1–60, default 10)Settings → Display
Output Font ScaleText size of the overlay (0.5–2.0, default 1.0)Settings → Display

Click-Through Mode

By default, the overlay is in click-through (locked) mode, meaning your mouse clicks pass through it to the game behind it. This prevents the overlay from interfering with gameplay.

To toggle click-through mode:

  • Type /mydps lock in chat
  • Toggle the Lock Combat Output checkbox in Settings
Unlock the overlay temporarily when you need to reposition it, then lock it again so it does not intercept your clicks during combat.

Filtering What Appears

You can control which types of events show up in the overlay using these Settings toggles:

ToggleWhat It Filters
Show My MissesYour attacks that missed
Show Missed MeEnemy attacks that missed you
Show Hit MeDamage you received from enemies
Show Crit HealsCritical heal events
Show Damage ShieldDamage shield procs
These filters control what appears in the combat overlay and floating text — they do not affect your DPS or damage totals. Incoming damage (Hit Me) never counts toward your DPS or battle totals regardless of this setting. The exception is Crit Heals: if "Show Crit Heals" is disabled, critical heals will not be counted in your Healing totals either.
