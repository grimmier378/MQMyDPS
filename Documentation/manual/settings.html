Settings

Open the settings window by clicking the gear icon in the menu bar or typing /mydps config. Settings are organized into five tabs: Display, Colors, FCT, Theme, and Patterns.

The settings window showing the Display tab.

Display Tab

Controls what information is shown and how the interface behaves.

Checkboxes

OptionDefaultWhat It Does
Show TypeOnDisplay the damage type (melee, DoT, etc.) in the combat overlay
Show TargetOnDisplay the target name in the combat overlay
Show My MissesOnInclude your missed attacks in tracking and display
Show Missed MeOnInclude enemy misses against you
Show Hit MeOnInclude incoming damage in tracking and display
Show Crit HealsOnInclude critical heals in tracking and display
Show Damage ShieldOnInclude damage shield procs in tracking and display
Track PetOnInclude pet damage in your totals
Show Combat OutputOnShow the combat overlay window
Sort Newest FirstOnDisplay most recent battles at the top of history
Auto StartOffBegin tracking automatically when you log in
Lock Combat OutputOnMake the combat overlay click-through

Sliders

SliderRangeDefaultWhat It Controls
Display Time1 – 60 sec10How long entries stay visible in the combat overlay
Battle End Delay1 – 30 sec10Seconds to wait after combat before finalizing a battle
Font Scale0.5 – 2.01.0Text size in the main window
Output Font Scale0.5 – 2.01.0Text size in the combat overlay
If the main window feels cramped, try increasing Font Scale to 1.2 or widening the window. The Current Battle tab automatically adapts its columns to fit the available width.
Type an exact value. Every slider in MQMyDPS supports precise entry: hold Ctrl and click the slider to open a small box where you can type the exact number, then press Enter (or Apply). This works for all sliders — here, on the FCT tab, and in the Icon Picker.

Colors Tab

Customize the colors used throughout the interface. Click any color swatch to open a color picker with an alpha (transparency) slider.

Background Color

Controls the background color of the combat overlay, including transparency. Lower the alpha value to make the overlay more see-through.

UI Colors

These colors are used in tables, graphs, and text throughout the main window:

ColorWhere It Appears
Damage TargetTarget names in damage tables
Heal TargetPlayer names in healing tables
DPSDPS values in tables and the menu bar
DurationDuration values in tables
AverageAverage damage values
TotalTotal damage and healing values
Damage type colors (used in FCT and the combat overlay) are configured in the FCT tab, not the Colors tab.

FCT Tab

All Floating Combat Text settings are in this tab. For a full guide, see the Floating Combat Text page. This tab includes the master enable toggle, per-type visibility checkboxes, animation sliders, per-type color pickers, icon configuration, and bone anchoring dropdowns.

Theme Tab

Choose from 11 visual themes that change the overall look of all MQMyDPS windows. Select a theme from the dropdown to apply it immediately. Available themes include various dark and light styles.

Patterns Tab

View and edit the chat patterns that MQMyDPS uses to recognize damage, healing, and miss messages. Patterns are stored in a per-server JSON file and can be customized for different server types (live, emulated, etc.). For full details on editing patterns, see the Chat Patterns page.

Peers Display

The controls for sharing data with your other characters aren't in this settings window — they live on the Peers tab of the main window (the All/Server/Group/Raid filter) and on a few chat commands (/mydps peers, /mydps filter). Your chosen filter and whether peers are shown are remembered per character along with everything else. See Peers for the full guide.

Saving Settings

Settings are saved automatically in these situations:

  • When you zone
  • When you log out or go to character select
  • When the plugin is unloaded
  • When you close the settings window
  • When you click the Save button in the settings window

Each character on each server has their own settings file, so you can have completely different configurations for each of your characters.

If you force-close EverQuest without properly logging out, your most recent settings changes may not be saved.
